calculateAverage — reduce суммирует оценки и делит на длину; пустой массив → 0.



getTopStudents — filter отбирает студентов со средним ≥ 85, map возвращает имена.



getGroupAverage — reduce по всем студентам с calculateAverage каждого.



spread (...) создаёт новые объект и массив оценок, исходные данные не мутируются.
